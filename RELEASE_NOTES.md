# Allgemeine Angaben

Die Inhalte des Repositories werden zum überwiegenden Teil automatisch generiert, so dass ein Commit/Push immer mehr oder weniger das komplette Repository ändert. Langfristig ist hier eine Änderung geplant, so dass nur "wriklich" inhaltlih geänderte Dateien aktualisiert werden - und auch eine Änderungsnotiz erstellt wird.

Die Generierung der HTML/PDF Dateien ist aktuell noch manuell, insofern erfolgt dieses getrennt von dem restlichen Repository Inhalten. Der aktuellste Stand ist immer nur im Vault enthalten.

## Aktueller Stand

**2.5.2026**
- die Verlinkung zwischen Notizen sollte jetzt über relative Pfade passieren, so dass eine Kopie der Inhalte in einen anderen Vault keine Probleme mit der Verlinkung mehr macht.
- es gab ein paar Encodingsprobleme, die jetzt (hoffentlich) alle gefixed sind.
- es wurden zusätzliche Tags eingebaut, die eine bessere Verlinkung zwsichen Namespace-Einträgen und den Groups und Controls mittels dataviewjs erlaubt.
- einige Formatierungen wurden zur besseren Lesbarkeit umgestellt.
