# Liste der Controls der Klasse "BSI Anforderungen zum Risikomanagement"

Quellkatalog: [[../../Quellkataloge/Risikomanagement/BSI Anforderungen zum Risikomanagement|BSI Anforderungen zum Risikomanagement]]


```dataview
TABLE WITHOUT ID
	file.link AS "Control", 
	stmt_practice AS "Praktik"
FROM "BSI/Grundschutz/Anwenderkatalog"
WHERE 
	oscal_class = "BSI-Anforderungen-zum-Risikomanagement"
SORT file.name ASC
```
