# TEST - Änderungen und Tests 
> [!info]- Praktik TEST Änderungen und Tests:
> | | |
> | - | - |
> | auch bekannt als: | Veränderungsmanagement |
> | Schwerpunkt: | Organisatorisch |
>
> > Die Praktik "Änderungen und Tests" stellt sicher, dass alle geplanten Veränderungen an Informationssystemen systematisch und kontrolliert ablaufen, um ungewollte Störungen, Sicherheitsrisiken oder Compliance-Verstöße zu vermeiden (Change Management).
