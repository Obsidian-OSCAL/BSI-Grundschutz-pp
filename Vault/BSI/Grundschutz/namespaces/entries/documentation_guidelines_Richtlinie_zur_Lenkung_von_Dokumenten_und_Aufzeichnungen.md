# [documentation_guidelines](../documentation_guidelines.md) &rarr; Richtlinie zur Lenkung von Dokumenten und Aufzeichnungen

| | |
| --- | --- |
| ** UUID ** |  |

Ein Verfahren zur Lenkung mindestens aller für das ISMS direkt und indirekt relevanten Dokumente muss eingerichtet und verankert werden. Ziel dieses Verfahrens ist die Sicherstellung der Nachvollziehbarkeit über den gesamten Lebenszyklus eines Dokuments. Dies beinhaltet die Erstellung bzw. Übernahme der Dokumente mit Titel, Autor, Dokumenteneigentümer, Sicherheitsklassifikation, Erstelldatum sowie einheitlichen Formaten. Weiterhin umfasst es die Steuerung mit einem Änderungsmanagement (Versionierung), einer einheitlichen Veröffentlichung, einer angemessen geschützten Ablage und ggf. auch Archivierung sowie einer kontrollierten Rücknahme veralteter Dokumente.

### Controls mit "Richtlinie zur Lenkung von Dokumenten und Aufzeichnungen" Dokumentation

```dataviewjs
let pages = dv.pages()
  .where(p => p.stmt_documentation == "Richtlinie zur Lenkung von Dokumenten und Aufzeichnungen" &&
              p.file.etags.includes("#oscal_control"))
  .sort(p => p.file.name)
  .groupBy(p => p.file.folder)
  .sort(g => g.key);

let rows = [];

for (let group of pages) {
    let first = true;
    for (let page of group.rows) {
        rows.push([
            first ? group.key : "",
            page.file.link
        ]);
        first = false;
    }
}

dv.table(
    ["Verzeichnis", "Control"],
    rows
);

```
