# [[effort_level]] &rarr; 5

| | |
| --- | --- |
| ** UUID ** |  | 


In der Regel sind für die Umsetzung aufwändige, komplexe Maßnahmen oder eine individuelle Abwägung und Behandlung damit verbundener sekundärer Risiken erforderlich. Hierzu ist häufig tiefgehendes Expertenwissen oder der Einsatz entsprechender externer Dienstleister, sowie eine sorgfältige Planung  und Aufrechterhaltung notwendig. Beispiel: Aufbau georedundanter Rechenzentren.
