Tätigkeit im Zusammenhang mit Informationen der Institution, die ein Dritter für die Institution ausübt. Im Gegensatz zu IT-Produkten ist dies eine immaterielle Beschaffung, d.h. beschafft wird ein Recht zum Abruf einer Dienstleistung gegenüber dem Dienstleistenden. Beachten Sie, dass ein Vertrag sowohl IT-Produkte als auch Dienstleistungen enthalten kann, z.B. ein Smartphone mit Cloudspeicher-Dienst. Die Dienstleistungen haben eine weitere Unterart, das sogenannte Outsourcing, welches sich mit der Auslagerung von (Teil-)Geschäftsprozessen an Dienstleister beschäftigt.
