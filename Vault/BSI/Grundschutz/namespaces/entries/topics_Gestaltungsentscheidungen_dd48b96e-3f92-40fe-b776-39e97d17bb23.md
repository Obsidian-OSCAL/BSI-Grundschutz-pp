# [topics](../topics.md) &rarr; Gestaltungsentscheidungen

| | |

Bevor mit der Umsetzung des Anforderungspakets begonnen wird, gilt es zentrale Gestaltungsentscheidungen zu treffen. Parameter sind variabel gestaltbare Elemente innerhalb einer Anforderung, die Editoren, Auditoren und Anwendern Spielräume aufzeigen und zur automatisierten Prüfung genutzt werden können. Sie ermöglichen es, Anforderungen an spezifische Kontexte anzupassen. Sollte für eine Zielobjekt aus unterschiedlichen Vorgaben unterschiedliche Parametereinstellungen gefordert werden ist immer die sicherste Einstellung zu wählen.
