# [[result]] &rarr; Praktik

| | |
| --- | --- |
| ** UUID ** |  | 


Praktiken bündeln Tätigkeiten nach (Teil-)Prozessen, deren Zuständigkeit bestimmten Rollen zuordenbar sind. Dies ermöglicht eine schnelle Zuordnung von Anforderungen zu Prozessen und zuständigen Personen oder Rollen, die für die Umsetzung führend verantwortlich sind. Praktiken bieten außerdem einen ersten Überblick über die Prozess- und Themenlandkarte des Grundschutz++.
