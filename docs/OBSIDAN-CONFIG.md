# Konfigurationsempfehlungen
  
## Plugins

Einige der Dokumente in diesem Vault benötigen zusätzlich Plugins:
* [Dataview](https://obsidian.md/plugins?id=dataview) <br> Zusätzlich muss in der Konfiguration des Plugins Javascript aktiviert sein (dataviewjs)
* [Enhanced Tables](https://obsidian.md/plugins?id=enhanced-tables)
  
**Probleme**

Bei der Verwendung von Plugins kann es zu Seiteneffekten mit anderen Plugins kommen, sollten bestimmte Ansichten nicht richtig funktionieren, kann man dies in der Regel dadruch feststellen, dass man zunächst alle Plugins ausser den oben genannten Plugins deaktiviert und dann nach und nach aktiviert. Wenn das problematische Plugin idnetifiziert hat, kann man evtl. in den Optinionen Funktionen, die nicht benötigt werden deaktivieren, dies kann im Einzelfall helfen. 

Bekannte Probleme:
* [Table Extended](obsidian://show-plugin?id=table-extended) <br> Das Plugin hat optinale Einstellungen, die Aktivierung von "Experimental: Extended Native Table Syntax" führt zu Problemen mit dem "Enahnced Tables" Plugin

## Anzeigenkonfiguration

Wichtig:
* *Link-Format* (Optionen -> Dateien & Links -> Links): "Relativer Pfad zur Datei"

Persönliche Empfehlungen:
* *Interne Links automatisch aktualisieren* (Optionen -> Dateien & Links -> Links): An
* *Lesbare Zeilenlänge* (Optionen -> Editor -> Anzeige): Aus
* *Thema* (Optionen -> Darstellung): Minimal
